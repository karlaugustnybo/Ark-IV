# Evidence and interpretation

No private historical execution result is published with these tools. Keep
provider responses, timestamps, IDs, artifact versions, receipts, source-derived
counts, profiles and measured outcomes in private run directories.

The supported evidence model separates synthetic code checks, source-specific
measurements, conditional forecasts and complete builds. A synthetic geometry
probe can exercise holes, antimeridian handling, SQL spill and optional tiles;
it does not validate global coverage or source redistribution rights. A
successful transfer establishes the selected bytes and hashes, not scientific
completeness. A successful configured pipeline can still defer lossless audits.

For a new run, preserve exact payload hashes, sources, profile, environment,
requested resources, stage outcomes, persistence status and cleanup evidence.
Explicitly record unavailable counters and unmeasured phases. Do not infer a
quota from shared capacity, a tariff from unsettled account usage, a global ETA
from a small fixture, or a biological trend from changed pipeline exports.
